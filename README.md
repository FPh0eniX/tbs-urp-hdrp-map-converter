# TBS URP/HDRP Map Converter

Программа для сборки и разбора PBR-карт по каналам. Файлы перетаскиваются мышкой
из проводника, всё считается локально.

## Запуск

Двойной клик по `run.bat`. Если окно не открылось, запусти `run_debug.bat`,
он оставляет консоль с текстом ошибки. Ошибки также пишутся в `error.log`.

Если папку `.venv` пришлось удалить или проект переехал на другой компьютер,
запусти один раз `setup.bat`, он поставит зависимости заново.

## Вкладки

**Собрать.** Выбираешь раскладку, кидаешь карты в строки R, G, B, A и жмёшь
«Сохранить текстуру». Можно кинуть сразу несколько файлов или папку на окно,
тогда программа разложит их по каналам сама, по именам файлов.

Для каждого канала настраивается:
- откуда брать значение, если исходник цветной (Авто берёт среднее по RGB);
- инверсия, она же превращение roughness в smoothness;
- заливка постоянным значением, если карты нет.

**Разобрать.** Кидаешь упакованную текстуру, получаешь четыре отдельных карты.
Суффиксы имён подставляются из раскладки, у каждого канала своя галка инверсии.
Так можно вытащить roughness из готовой маски, поправить его и собрать обратно.

**Пакетно.** Кидаешь папку, программа сама группирует файлы в наборы по именам
и за один проход собирает для каждого набора два результата: маску и base color
с альфой. Base color собирается только там, где нашлась opacity. Перед запуском
видно таблицу: что нашлось, что будет залито константой, где будет инверсия
и почему какой-то результат пропущен. Исходники программа никогда не перезаписывает.

## Раскладки

| Раскладка | R | G | B | A |
|---|---|---|---|---|
| Unity Mask Map (URP / HDRP) | Metallic | AO | Detail | Smoothness |
| Base Color + Opacity (URP / HDRP) | Base Color R | Base Color G | Base Color B | Opacity |
| URP Metallic Smoothness | Metallic | свободный | свободный | Smoothness |
| ORM (Unreal, glTF) | AO | Roughness | Metallic | нет |
| RMA | Roughness | Metallic | AO | нет |
| Свободная раскладка | сам | сам | сам | сам |

## Как готовую маску подключить в URP

1. У текстуры в инспекторе снять галку **sRGB (Color Texture)**. Это данные, не цвет.
2. Положить одну и ту же текстуру и в слот **Metallic**, и в слот **Occlusion**
   материала Lit. Unity сама возьмёт красный канал под металл, зелёный под AO
   и альфу под гладкость.
3. Синий канал стандартный URP Lit не читает, detail mask нужен только в HDRP
   или в своём шейдере на Shader Graph.

## Base color с альфой

В раскладке «Base Color + Opacity» цвет копируется из base color без изменений,
а в альфу идёт карта opacity. Base color достаточно кинуть в любую из строк
R, G, B, он сам встанет во все три.

В Unity:

1. Галку **sRGB (Color Texture)** у такой текстуры оставить включённой.
   Она влияет только на RGB, альфа всегда читается линейно.
2. Текстуру положить в слот **Base Map**.
3. В материале включить **Alpha Clipping** или поставить **Surface Type: Transparent**.
4. **Smoothness Source** оставить на **Metallic Alpha**. Если выбрать Albedo Alpha,
   URP начнёт читать альфу как гладкость и перестанет использовать её
   как прозрачность.

## Что важно знать про пиксели

- Каналы копируются как есть, без гамма-коррекции. Карты данных линейные,
  и переводить их не надо.
- Исходники разного разрешения приводятся к общему, по умолчанию к самому
  большому, фильтром Lanczos.
- 16 бит на канал поддерживаются на запись и на чтение серых карт.
  Pillow не читает 16-битные цветные PNG в полной точности, такие файлы
  приходят как 8 бит. Для карт данных это не проблема, они почти всегда серые.
- Roughness и smoothness это одно и то же наоборот. Инверсия ставится
  автоматически, если имя файла говорит про roughness, а канал ждёт smoothness.

## Распознавание имён

Пакетный режим и авторазбор по именам понимают такие окончания:

| Роль | Окончания |
|---|---|
| Base Color | `BaseColor`, `Base_Color`, `BaseMap`, `Albedo`, `Diffuse`, `Diff`, `Color`, `Col`, `BC` |
| Opacity | `Opacity`, `OpacityMask`, `Alpha`, `Transparency`, `Cutout` |
| Metallic | `Metallic`, `Metalness`, `Metal` |
| AO | `AO`, `Occlusion`, `Ambient_Occlusion` |
| Roughness | `Roughness`, `Rough` |
| Smoothness | `Smoothness`, `Smooth`, `Gloss`, `Glossiness` |
| Detail | `Detail`, `DetailMask` |
| Height | `Height`, `Displacement` |

Имя набора это то, что осталось слева. Например `T_Rock_01_Ambient_Occlusion.png`
даёт набор `T_Rock_01` и роль AO. Файлы без узнаваемого окончания пропускаются.

Base color, в который альфа уже вшита, тоже узнаётся: `BaseColorAlpha`,
`AlbedoTransparency`, `AlbedoAlpha`. Если в наборе есть и обычный base color,
берётся обычный. Поэтому повторный запуск по папке с результатами не подхватит
собственный вывод вместо исходника.

## Файлы проекта

- `core.py` — работа с пикселями: чтение, ресайз, сборка, запись PNG.
- `presets.py` — раскладки каналов и разбор имён файлов.
- `app.py` — окно.

## Сборка exe

`build.bat` собирает один самостоятельный файл в папке `dist`,
которому не нужен ни Python, ни виртуальное окружение. Настройки сборки
лежат в `build.spec`. Готовые сборки выкладываются в разделе Releases.
